# Трекер поїздок

Застосунок для тижневого обліку поїздок з одногрупниками: з ким їхав, скільки кому віддати і коли їхав маршруткою.

**Відкрити:** https://s1xen7ag.github.io/poizdky/

## Що вміє

- На кожен день вибираєш, з ким їхав (з одногрупником), маршрутку або «Не їду».
- Сам рахує, скільки віддати кожному за тиждень. Поїздка в один бік коштує половину ціни, а суму за окремий день можна змінити.
- Гроші можна віддавати в кінці тижня (кнопка «Розрахувались») або одразу після поїздки (галочка «Віддано» біля дня).
- В історії видно всі тижні і що ще не віддано.

## На телефоні

Застосунок можна поставити на головний екран, і він відкриватиметься окремо, без панелі браузера, навіть без інтернету.

- **Android (Chrome):** вкладка «Люди» → «Встановити», або меню ⋮ → «Встановити застосунок».
- **iPhone (Safari):** «Поділитися» → «На початковий екран». Потім відкрий застосунок зі значка й підключи GitHub ще раз: в iPhone застосунок зі значка має окреме сховище.

## Де зберігаються дані

Спочатку все зберігається в браузері на твоєму пристрої. Щоб дані не загубились і були однакові на телефоні й на компʼютері, підключи GitHub: вкладка «Люди» → картка «GitHub».

Дані лежать у файлі `poizdky.json` у приватному репозиторії [`s1xen7ag/poizdky-data`](https://github.com/s1xen7ag/poizdky-data). Бачиш його тільки ти. Цей репозиторій із застосунком публічний, але в ньому немає жодних твоїх даних.

Щоб підключити GitHub, створи токен на https://github.com/settings/personal-access-tokens/new:

1. Repository access: **Only select repositories** → `poizdky-data`.
2. Permissions → Repository permissions → **Contents: Read and write**.
3. Скопіюй токен і встав його в застосунку. Токен зберігається тільки в браузері пристрою, на якому ти його вставив.

## Як влаштовано

Увесь застосунок це один файл `index.html` без збірки й залежностей. Він працює на GitHub Pages і звертається до GitHub API прямо з браузера.
